# Harness Engineering Brain

Vault de segundo cérebro sobre Harness Engineering — a disciplina de construir
o ambiente que circunda um modelo de IA para guiar, corrigir e amplificar seu
comportamento em tarefas de engenharia de software.

## Fontes primárias

- [OpenAI — Harness Engineering](https://openai.com/index/harness-engineering/)
- [Anthropic — Harness Design for Long-Running Apps](https://www.anthropic.com/engineering/harness-design-long-running-apps)
- [Martin Fowler — Harness Engineering for Coding Agent Users](https://martinfowler.com/articles/harness-engineering.html)
